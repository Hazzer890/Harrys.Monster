Why they exist

Most of these started the same way. I needed to do something small, the websites that do it wanted an upload, an account or a subscription, and it was quicker to build my own. They live on subdomains of this site (the Monsters menu up top) and anyone can use them.

Where it's possible the work happens in your browser and the file never leaves your device. The ones that need a server say so.

Files

pdf. Merge, split, compress, rotate, reorder, sign and resize PDFs, and convert between PDFs and images. No upload and no backend.

metadata. Drop a file and see every piece of metadata it carries (the GPS position in a photo, the author of a Word document), then download a copy with it removed. It reads the cleaned file back to show you what's left.

mp3. Fixes the tags and cover art on an album of MP3s so iTunes on Windows imports it as one album with one cover. The audio itself is never touched.

facecutout. Drop a photo and get each head in it as a PNG with a transparent background, using face models that run in the browser.

send. File transfer between two browsers. The sender gets a six-digit code, the receiver types it in, and the file goes straight across over WebRTC with nothing stored on a server.

dl. Paste a video link or upload a video and get an MP3 or MP4 back. This one runs on my server, with limits on job size and time.

Uni

timetable. Exports a Curtin timetable to a calendar file for Google Calendar, Outlook or Apple Calendar.

eggs. A study site for me and my friends, in the style of old-school Reading Eggs: walkthroughs, flashcards, problems and races for the units we're taking. The preview is open, the study accounts are private.

For fun

dope. A Perth-themed parody of Dope Wars, a 30-day game with an online leaderboard.

grace. A live ranking board that updates for everyone watching as it's edited.

Keeping an eye on it

analytics. The analytics for all of the above is mine as well, a small collector and dashboard on my own server that counts pageviews, clicks, scroll depth and errors. It's the "little data" the footer mentions.
