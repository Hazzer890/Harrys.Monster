Measured with the chrome-devtools MCP tools (`performance_start_trace` for LCP/CLS, `list_network_requests` for third-party count, `evaluate_script` for frame timing). Third-party requests are those to a host other than `localhost` (`fonts.googleapis.com`, `fonts.gstatic.com` x2, `analytics.harrys.monster`); the inline `data:` SVG noise texture has no host and isn't counted. Both columns are the second of two back-to-back runs per page, the first run warming the browser. Before was measured against a `git archive main` export served from a scratch directory, After against the branch working tree, both with the same server, emulation and procedure.

Read the LCP rows with the run-to-run spread in mind. The two Before runs on index were 1,104 ms then 1,569 ms, and on guide-to-github 1,409 ms then 1,099 ms, so a single build moves by 300 to 500 ms between one reload and the next. `python3 -m http.server` is single-threaded HTTP/1.0 with no gzip, and under Slow 4G the five render-blocking stylesheets queue behind each other and behind the document, which is where that variance comes from. Differences of a few hundred milliseconds between the two columns are inside that noise and should not be read as a result either way. On guide-to-github the LCP element is text (`p.contact-intro`), with no resource on its path at all, so nothing in this branch could move it except by freeing up bandwidth and main thread ahead of first paint.

What is outside the noise is the frame timing and the weight. Idle and scroll long-frame counts are zero on both pages now, and achieved frame rate roughly doubled, which was the point of the branch. CLS held at 0.00. Third-party requests aren't at zero: the Google Fonts requests are gone, but one request to `analytics.harrys.monster` remains on each page, which is the site's own first-party analytics endpoint rather than a genuine third party. Index now transfers about 258 KB across 11 requests, down from 578 KB, after dropping the 2x headshot candidate (389 KB) and cutting the halftone SVG to the tower alone (112 KB to 53 KB). Below 900px the inner pages no longer request the SVG at all, so guide-to-github is down to 9 requests on a phone.
