Reading building numbers

Python YOLOv8 Computer vision Curtin coursework

The job

The assignment for Machine Perception at Curtin in 2025 was to read the building numbers on the Bentley campus from photos. It's four tasks that chain together: find the number in the photo, cut out each character, recognise each character, then run the lot as one program that takes a photo and writes out the number. Pretrained OCR wasn't allowed.

The data

I went with trained models from the start, which made the dataset the real work. Two other students and I photographed and labelled the campus numbers together on Roboflow, and we made the set public so anyone else in the unit could use it (some of them folded it into their own). We labelled a few look-alike signs as negatives so the detector would learn to leave them alone. After augmentation, which covered rotation, crop, shear, blur, noise and lighting changes, my detection set was 2,717 images.

For the character classifier I added synthetic data. A short Python script draws characters in the font the campus signs use, over varied backgrounds, colours and contrast.

The pipeline

  • Find the number. A YOLOv8 nano detector, trained for 300 epochs at 800 pixels so that small, distant numbers keep their detail. It keeps the most confident box and grows it by 4% so no character gets clipped. I picked nano so the submission would fit under the file size limit.
  • Cut out the characters. A second detector that only looks for "a character" and doesn't try to read it.
  • Read each one. A YOLOv8 classifier over the digits 0 to 9 and the letters A to D, the suffixes the campus uses most.
  • Join them up. The full pipeline sorts the character boxes left to right and writes the number to a text file. A photo with no building number in it produces nothing.

Letting YOLO choose its own batch size kept crashing the lab computers by filling the GPU, so for the classifier I fixed it at 17, the average of what it had been choosing.

Results

On my validation photos it found 4 of 4 numbers and ignored the one photo without a number, cut out 12 of 12 characters, and read 11 of the 12. The miss was a badly skewed 4 that it read as a 1, the same character the cropping had trouble with.

That's a small set, so I'd call it working on most inputs and not all of them. Next I'd straighten each crop before reading it, and check the output against what a campus number can be, which is digits with an optional A to D on the end.
