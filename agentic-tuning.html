An agent that tunes machine-learning models

Python Claude API PyTorch Agentic loop Curtin coursework

The problem

Hyperparameter tuning eats time. Train, wait, read the metrics, adjust, repeat. Each cycle needs judgement, but it is the same kind of judgement every time. That combination, a slow loop plus repeatable judgement inside known bounds, is exactly the shape of work an agent should take over.

The approach

I wrapped my training pipeline in an agentic loop built on the Claude API. The agent proposes a configuration, launches the run, reads the results, reasons about what to change, and tries again. It keeps a log of every attempt and the reasoning behind it. My role changed from turning knobs to setting the bounds, auditing the log, and stepping in when the reasoning drifted.

The clearest run was a Machine Learning assignment at Curtin: predict the peak pressure at sensors around a tank explosion, scored on a Kaggle leaderboard. I wrote the prompt template, the rules the agent couldn't break, the results format and the first training script. Each round the agent changed one thing and wrote the full training script for it, and the round was judged on both my validation score and the leaderboard.

What happened

It ran 21 rounds. The leaderboard error went from 0.159 at the baseline to 0.134 with the final model, an ensemble of 30 transformers.

Round 7 mattered most. Until then my validation score looked about 0.03 better than the leaderboard, and the agent's notes worked out why: each explosion scenario has 27 sensor rows, and splitting the data row by row put the same scenario on both sides of the split. Grouping the split by scenario closed the gap, so every decision after that was made on a number I could trust.

Plenty of rounds failed. Adding noise to the inputs hurt three times, mixup hurt, and one change looked great on validation and worse on the leaderboard, so it was thrown out as overfitting. The prompt kept a list of dead ends and steered the agent away from them, which made the log of failures as useful as the wins.

The outcome

A tuning process I supervised rather than babysat, and one I've also used on a Machine Perception assignment. The pattern generalises well past coursework: give an agent a measurable objective, a bounded search space, and an audit trail, and it will grind through iterations that would otherwise consume your evenings.
